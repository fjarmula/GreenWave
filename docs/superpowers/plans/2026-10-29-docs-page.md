# Documentation Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bilingual `/docs` page with six tabs that holds the contest's §5.2 documentation, reachable from the standard workspace menu.

**Architecture:** Typed bilingual content (`lib/docs/content.ts`) rendered by small block components. A WAI-ARIA tab strip whose active tab lives in the URL hash. Page chrome copied from Diagnostics. Pure helpers carry the interaction logic so the node-environment Vitest suite can test it; a `playwright-cli` pass covers real interaction.

**Tech Stack:** Next.js 16.4 (App Router), React 19.3, TypeScript, Tailwind 4 + `globals.css`, lucide-react, Vitest (`environment: "node"`), `@playwright/cli`.

**Spec:** `docs/superpowers/specs/2026-10-29-docs-page-design.md`

## Global Constraints

- Frontend only. No backend, contract, or simulation change. No new dependency, no lockfile change.
- Read the relevant guide in `frontend/node_modules/next/dist/docs/` before writing route code (`frontend/AGENTS.md`).
- Content copy is written fresh. No English sentence of 40+ characters may appear verbatim in `README.md`, `GreenWave_ARCHITECTURE.md`, `backend/README.md`, or `frontend/README.md` (enforced in Task 5).
- Simulation-only wording stays explicit. Never imply control of real signals.
- Full PL/EN parity. Polish is the default. GreenWave is a proper noun in both languages. Geographic and dataset names stay in Polish in both languages.
- Facts come from code, `README.md`, `GreenWave_ARCHITECTURE.md`, and `backend/data/raw/MANIFEST.json`, never from memory.
- Short UI labels go through `polish.ts` + `t()`. Docs body copy comes from `docsContent[language]` and is not passed through `t()`.
- Light and dark themes. At 360 px width the page never scrolls horizontally.
- Frontend check (from `frontend/`): `npm run lint && npm run typecheck && npm run format:check && npm test && npm run build`.
- Git: work on branch `feat/docs-page` (created with human approval). No push, no PR without the human. Commit subject `<category>: <message>`. Stage explicit paths only. End messages with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Browser checks only through `playwright-cli`, with output under `.tmp/playwright/`.

## Review Focus

1. Unknown or malformed hash (`""`, `"#"`, `"#foo"`, `"#DATA"`, `"#data?x=1"`) opens About and never throws. Test in Task 1.
2. Switching PL/ENG while on `#data` stays on Data. Ids are language-neutral (parity test, Task 2), checked in the browser in Task 6.
3. At 360 px, the tab strip, tables, and code scroll inside their own boxes and the page never scrolls sideways. Checked in the browser in Task 6.
4. Clipboard missing or rejecting (plain-HTTP LAN phone): the copy button shows "Copy failed" with no uncaught error. Test in Task 3.
5. Back/forward after switching tabs moves the selected tab with the hash. Checked in the browser in Task 6.
